Firmware & ROM flasher

Flash firmware releases and upload your own ROM dumps to the Rollin' Llama wavetable board — entirely in the browser. ROM files are verified and converted locally; nothing is uploaded anywhere.

This page needs WebMIDI and WebUSB — use Chrome or a Chromium-based browser.

Volume

Headphone / line-out level, set live while the board is in normal (MIDI) mode. The board stores the value a few seconds after the last change and restores it on power-up.
